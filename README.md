# 🛰️ Orbital Guardian AI – DevSecOps

## Objetivo
Aplicação web institucional sobre o projeto Orbital Guardian AI, criada para demonstrar práticas de Cloud Computing, DevSecOps, CI/CD, segurança e monitoramento no Azure.

## Tecnologias
- React + Vite
- Azure App Service
- GitHub Actions
- Azure Key Vault
- Application Insights
- Azure Monitor

## Funcionalidades
- Página institucional
- Explicação do problema do lixo espacial
- Seção sobre monitoramento orbital
- Conexão com ODS 9, 11 e 13
- Dashboard ilustrativo com métricas orbitais

## Infraestrutura
A aplicação foi hospedada no Azure App Service com deploy automatizado via GitHub Actions.

## Segurança
- GitHub Secrets para credenciais
- Azure Key Vault para armazenamento de secret
- HTTPS ativo
- IAM configurado

## Monitoramento
- Application Insights ativo
- Alert Rule configurada
- Logs e métricas acompanhados
